# City Hub Comparison Audit — 2026-10-15

Scope: comparison-first product direction, Bangkok–Kranj shared links, map lifecycle, mobile geometry, live-feed isolation, and release verification.

## Fixed

- Made Split Compare the primary view while retaining the complete single-city dashboard behind the Compare toggle.
- Replaced the app-wide blank lazy-load state with a visible comparison loading surface and a recoverable failure state.
- Removed the hidden dashboard map while comparison is active. Compare now creates only the maps it displays and releases them before the dashboard map mounts.
- Paused all-city risk, stress, news, forecast, and Bangkok anomaly polling while comparison is active. The comparison fetches current AQI and weather only for its selected cities.
- Seeded comparison from pinned cities when available; otherwise it opens active city versus Kranj. Shared `?city=` links update pane one after URL hydration.
- Kept green space and GDP-per-capita clearly marked as reference, mixed-year indicators. Current AQI and temperature remain Open-Meteo feeds with fetch-age labels. GDP per capita is explicitly an output proxy, not household income.
- Reworked the mobile relationship controls into a bounded grid. Both metric selectors fit at phone widths; no horizontal document overflow remains.
- Simplified the phone comparison header to brand + Compare because each pane already owns its city and lens controls.

## Remaining Risks

| Severity | Item | Boundary / next step |
|---|---|---|
| Medium | Curated economic and green-space indicators span different years and administrative boundaries. | They are visibly marked `REFERENCE · MIXED YEARS`. Move them into a typed per-value provenance registry before causal or policy claims. |
| Medium | Current AQI and weather depend on Open-Meteo availability. | Failed responses render as unavailable and never fall back to fabricated values. Add a second cited provider only where licensing and units match. |
| Low | Main, Firebase, MapLibre, and worker bundles exceed Vite's 500 kB advisory threshold. | Split non-comparison dashboard features further; Split Compare is already lazy-loaded. |
| Low | Live traffic is available only when a Mapbox token is configured. | The traffic control stays absent without a token; do not imply traffic coverage when it is unavailable. |

## Product Boundary

The system can compare any built-in or user-resolved city spatially. That does not mean every city has the same quantitative coverage. Current environmental observations, reference indicators, and absent values remain distinct in the interface so visual comparison does not become a false claim of causal correlation.
